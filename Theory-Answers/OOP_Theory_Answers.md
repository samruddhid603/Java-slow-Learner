Q1. What is Java?

Java is a high-level, object-oriented and platform-independent programming language. It was developed by Sun Microsystems. Java is used to develop web applications, mobile applications, desktop applications and software. Java programs can run on different operating systems with the help of JVM (Java Virtual Machine). It is simple, secure and easy to learn.

 Q2. What is OOP?

OOP stands for Object-Oriented Programming. It is a programming approach based on classes and objects. It helps programmers to organize code into smaller and reusable parts. OOP makes programs easier to understand, maintain and modify. The four main principles of OOP are Encapsulation, Inheritance, Polymorphism and Abstraction.

 Q3. What is a Class?

A class is a blueprint or template used to create objects. It contains variables and methods. Variables represent the data, while methods represent the actions performed by an object. A class does not occupy memory for its instance variables until an object is created. For example, Student is a class that can contain name, age and marks.

Q4. What is an Object?

An object is an instance of a class. It represents a real-world entity and contains data and behaviour. An object has three main characteristics: state, behaviour and identity. State represents its data, behaviour represents its methods and identity makes it unique. For example, a student named Rahul can be an object of the Student class.

 Q5. What is Inheritance?

Inheritance is an important concept of Object-Oriented Programming. It allows one class to acquire the properties and methods of another class. The class that provides the properties is called the parent class, and the class that receives them is called the child class. In Java, inheritance is achieved using the extends keyword. It helps in code reusability and reduces code duplication.

 Q6. What is Encapsulation?

Encapsulation is the process of wrapping data and methods together into a single unit called a class. It is used to protect data from direct access. In Java, encapsulation is achieved by declaring variables as private and providing public getter and setter methods to access and modify them. It improves data security and makes the program easier to maintain.

Q7. What is Polymorphism?

Polymorphism means one name having many forms. It allows the same method or operation to behave differently in different situations. In Java, polymorphism is mainly achieved through method overloading and method overriding. Method overloading is compile-time polymorphism, while method overriding is runtime polymorphism. It makes programs flexible and reusable.

 Q8. What is Abstraction?

Abstraction is the process of hiding unnecessary implementation details and showing only the important features to the user. It helps to reduce complexity and makes programs easier to understand. In Java, abstraction is achieved using abstract classes and interfaces. For example, when we drive a car, we use the steering and brakes without knowing all the internal working of the engine.

Q9. What is a Constructor?

A constructor is a special member of a class that is used to initialize objects. It has the same name as the class and does not have any return type. A constructor is automatically called when an object is created. Java mainly supports two common types of constructors: default or no-argument constructors and parameterized constructors. Constructors help to initialize object data.

 Q10. What is Method Overloading?

Method overloading is a concept in Java in which two or more methods have the same name but different parameters in the same class. The methods can differ in the number or type of parameters. It improves code readability and allows the same method name to perform similar operations in different ways. Method overloading is an example of compile-time polymorphism.
